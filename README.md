# AI 自动混剪桌面版 MVP

第一阶段已完成：

- Windows 桌面 UI：左侧菜单、素材中心、镜头剪辑、任务中心、账号档案、设置
- SQLite 数据库初始化
- 账号档案新增、编辑、删除
- 素材扫描：选择文件夹、递归扫描视频、读取文件信息、生成缩略图
- FFmpeg/FFprobe 可选：配置后读取真实时长/分辨率并抽帧；未配置时生成占位缩略图
- 镜头编辑：模板 CRUD、复制模板、镜头 CRUD、排序、素材分类、字幕/配音开关
- TTS 接口预留：Windows TTS 生成 WAV、导入 WAV、检测真实语音时长 `voice_duration`
- 镜头素材自动匹配：按 `voice_duration` + 素材分类匹配素材，保存 `generation_shot_materials`
- 自动字幕：Whisper 接口预留，生成每镜头独立 ASS 字幕，并在 FFmpeg 成片时烧录
- 生产测试：一键创建测试账号/素材/模板/语音/字幕/匹配关系并尝试生成最终 MP4，输出耗时、状态、错误日志和报告

## 启动

默认启动新版商业 UI：

在仓库根目录运行：

```powershell
.\ai_mixcut_desktop\run.ps1
```

如需打开原 Tkinter 功能界面：

```powershell
.\ai_mixcut_desktop\run-legacy.ps1
```

或直接运行：

```powershell
& "C:\Users\Administrator\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" .\ai_mixcut_desktop\app.py
```

## 数据位置

- SQLite：`ai_mixcut_desktop/data/mixcut.db`
- 缩略图：`ai_mixcut_desktop/data/thumbnails/`
- 语音：`ai_mixcut_desktop/data/voices/`
- 字幕：`ai_mixcut_desktop/data/subtitles/`
- 生产测试报告：`ai_mixcut_desktop/data/production_tests/`
- 输出目录：`ai_mixcut_desktop/outputs/`
