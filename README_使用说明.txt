MixcutAI v1.3.6 使用说明

一、软件用途
MixcutAI 是 Windows 本地 AI 视频生产工具，可扫描视频素材、编辑镜头模板、生成配音与字幕、添加背景音乐并输出竖屏短视频。

二、系统要求
Windows 10 64 位或 Windows 11 64 位，建议 8GB 以上内存，并保持至少 10GB 可用磁盘空间。首次激活、在线配音、AI改写、更新和平台登录需要网络。

三、解压与启动
请完整解压 ZIP，不要直接在压缩包内运行。解压到普通可写目录后，双击 MixcutAI.exe。不要单独移动 EXE，browser 和 runtime 目录必须与 EXE 保持在同一文件夹。

四、卡密激活
首次启动会显示激活窗口。输入管理员提供的卡密并点击激活。卡密绑定本机，换机或提示已绑定其他设备时，请联系管理员解绑。

五、导入素材
打开“素材中心”，选择素材文件夹并扫描。也可以把视频放入软件目录下“混剪素材”的对应分类文件夹，再执行扫描。

六、生成视频
1. 在“账号档案”填写品牌和产品资料。
2. 在“镜头剪辑”创建模板并添加镜头。
3. 填写文案、生成配音、匹配素材。
4. 在“任务中心”创建并开始合成。
5. 成片完成后可预览或打开输出目录。

七、输出目录
默认输出目录位于：%LOCALAPPDATA%\MixcutAI\outputs。可在“系统设置”中修改。

八、自动更新
软件在授权验证后自动检查更新。更新前会备份用户数据库，下载文件通过 SHA256 校验，更新失败会恢复旧版本。更新时不要强制关机。

九、发布账号重新登录
进入“发布中心”→“账号管理”，找到对应账号并点击“登录”或“重新打开”。扫码、验证码、手机确认必须由用户本人完成。

十、常见问题
1. 软件打不开：确认已完整解压，并暂时允许安全软件放行 MixcutAI.exe。
2. 无法生成：检查素材是否存在、磁盘空间是否充足，并重新启动软件。
3. 配音失败：先检查网络；未配置外部服务时可使用 Edge TTS。
4. 卡密异常：确认网络正常，仍失败时将提示内容和机器码发给管理员。
5. 更新失败：重新启动旧版本后再次检查更新，用户数据库不会被删除。

十一、支持
客服/技术支持：请填写实际客服微信、邮箱或网站地址。
