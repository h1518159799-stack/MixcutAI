# Mixcut Studio UI Direction V3 — Airy AI Workshop

1. **产品与用户**：面向企业短视频运营人员，降低专业剪辑器的学习成本，让模板、文案、素材和预览同屏完成。
2. **气质**：明亮、可信、柔和、具有轻量 AI 产品感；参考用户提供的蓝灰色三栏工作台。
3. **布局**：固定宽导航 + 顶部品牌栏；镜头页使用“自定义模板 / 镜头创作 / 成片预览”三栏结构。
4. **字体**：中文使用 Noto Sans SC / Microsoft YaHei UI；标题 24–30px，正文不低于 12px，表单标签 12px。
5. **颜色**：雾白背景、白色内容面、蓝灰导航、清晰蓝主按钮；紫色只用于轻量 AI 状态和选中描边。
6. **形态**：14–22px 圆角、低透明蓝灰阴影、1px 冷灰边框；避免厚重玻璃和高饱和渐变。
7. **标志性差异**：镜头卡片以编号胶囊 + 状态条组织，右侧固定 9:16 成片预览，保持操作路径稳定。

## 业务约束

- 不出现系统模板类型，模板全部为用户自定义。
- 不提供手动时长输入；只读展示真实 TTS `voice_duration`。
- 保留素材匹配、TTS、字幕、静音、顺序和视频生成入口。
- Timeline 保持独立页面，不挤入镜头编辑页面。
